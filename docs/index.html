Automotive Visual Decomposer

Turn one automotive concept into a visual decomposition path: choose a style, choose a canvas, reason through the engineering structure, then output a production-ready image prompt.

Quick Start

Install to Codex

mkdir -p "$HOME/.codex/skills"
cp -R automotive-visual-decomposer "$HOME/.codex/skills/"
03

Workflow

  1. Install to your Codex skills directory.
  2. Ask Codex: "Use automotive-visual-decomposer. Visualize 线控转向."
  3. Agent asks for style, aspect ratio, and output mode.
  4. Agent returns a visual reasoning summary and an English rendering prompt.
